## ADDED Requirements

### Requirement: `d` — MR на вкладке Diff
`d` на строке MR в табе MRs режима проекта SHALL открывать MR detail выделенного MR сразу на вкладке Diff (дифф загружается при открытии). В футере и хелпе — `d diff`.

#### Scenario: Открыть дифф из списка
- **WHEN** курсор на !479 в табе MRs и пользователь нажал `d`
- **THEN** открыт экран !479 на вкладке Diff, в журнале фейка один вызов `Diffs`; `esc` возвращает к списку с курсором на !479
