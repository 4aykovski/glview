## ADDED Requirements

### Requirement: Экран To-Do
`T` SHALL открывать экран To-Do: список задач To-Do текущего пользователя по всему инстансу, шапка `To-Do · <хост>`, строка фильтров `state:pending  type:any` и справа `<загружено> из <всего>`. Колонки по приоритету: Target (`!479`, `#1318`, у коммита — короткий SHA, иначе `—`), Title, Action (переведённая подпись причины, неизвестная — `action_name` как есть), Ago, Author, Project (`—` без проекта). Порядок — сервера; страница 20, подгрузка за 5 строк до конца, курсор держится по ID задачи; поллинг 30 с на вершине стека.

#### Scenario: Список задач
- **WHEN** у пользователя задачи: `review_requested` на !479 проекта `platform/route-service` от anna.k и `mentioned` в #1318, язык ru
- **THEN** две строки: `!479 … ревью … anna.k … platform/route-service` и `#1318 … упоминание …`

#### Scenario: Неизвестная причина
- **WHEN** у задачи `action_name = okr_checkin_requested`
- **THEN** в колонке Action — `okr_checkin_requested`

#### Scenario: 80×24
- **WHEN** терминал 80×24, экран To-Do с данными, en и ru
- **THEN** ни одна строка не шире 80 колонок, строк не больше высоты

### Requirement: Фильтры To-Do
`s` SHALL переключать state по кругу pending → done, `t` — тип any → MR → issue, `backspace` — сбрасывать к pending/any; смена фильтра SHALL перезапрашивать список с первой страницы с новым поколением. `m` MUST NOT действовать. Пустые состояния: «В To-Do пусто» (pending), «Нет выполненных задач» (done), с типом — «Нет задач по фильтрам · backspace — сбросить».

#### Scenario: Только MR
- **WHEN** пользователь нажал `t`
- **THEN** строка фильтров `type:MR`, запрос с `type=MergeRequest`

#### Scenario: Ответ старого фильтра
- **WHEN** пользователь нажал `s`, а ответ на прежний фильтр пришёл позже нового
- **THEN** на экране список для state done

### Requirement: Превью задачи To-Do
Превью выбранной задачи SHALL показывать title цели (Bold), строку `<ref> · <проект> · <состояние цели> · <когда>`, строку `<Action> · <автор>` и `body` задачи в markdown (HTML → markdown), не длиннее 6 строк с обрезкой `…`. Превью — снизу, от 140 колонок — справа.

#### Scenario: Упоминание
- **WHEN** выбрана задача `mentioned` с телом заметки `@egor глянь, пожалуйста`
- **THEN** в превью строка `упоминание · d.orlov` и текст заметки

### Requirement: Открытие цели
`enter` SHALL открывать MR detail для цели `MergeRequest`, экран issue для `Issue` (проект — из задачи), для остальных типов и задач без проекта — `target_url` в браузере. Открытие MUST NOT отмечать задачу выполненной. `O` SHALL открывать `target_url` в браузере, `y` — копировать его, `o` — открывать `<хост>/dashboard/todos` с текущими фильтрами (умолчания не пишутся).

#### Scenario: MR
- **WHEN** курсор на задаче !479 и пользователь нажал `enter`
- **THEN** открыт MR detail !479 проекта задачи; `esc` возвращает к To-Do с курсором на этой задаче

#### Scenario: Коммит
- **WHEN** цель задачи — коммит
- **THEN** `enter` открывает `target_url` в браузере

#### Scenario: Ссылка на страницу To-Do
- **WHEN** фильтры `state:done type:issue` и пользователь нажал `o`
- **THEN** открыт `https://gitlab.example.com/dashboard/todos?state=done&type=Issue`

### Requirement: Отметить выполненной
`x` SHALL отмечать выбранную задачу выполненной без confirm: строка сразу убирается, счётчик в шапке уменьшается, тост «Готово: <ref>»; при ошибке строка возвращается на место, счётчик восстанавливается, тост ошибки. `X` SHALL спрашивать confirm «Отметить все задачи выполненными?» (по умолчанию «Отмена») и после «Да» отмечать все, тост «To-Do очищен», счётчик 0. В state done `x` и `X` MUST NOT показываться и действовать.

#### Scenario: Одна задача
- **WHEN** в pending 5 задач, курсор на !479, пользователь нажал `x`
- **THEN** вызван `MarkDone` с ID задачи, строки !479 нет, в шапке `To-Do 4`

#### Scenario: Ошибка
- **WHEN** `MarkDone` вернул ошибку сети
- **THEN** строка !479 на прежнем месте, в шапке снова `To-Do 5`, тост «Хост недоступен»

#### Scenario: Все
- **WHEN** пользователь нажал `X` и подтвердил
- **THEN** вызван `MarkAllDone`, список пуст («В To-Do пусто»), счётчика в шапке нет
