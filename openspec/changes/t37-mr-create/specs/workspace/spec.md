## ADDED Requirements

### Requirement: `n` в групповом табе MRs
`n` в групповом табе MRs workspace SHALL открывать форму New MR для проекта выбранной строки на любой строке группы, включая заголовок и «ещё N»; локальная ветка — из первой папки проекта в workspace. У архивного проекта `n` MUST NOT действовать.

#### Scenario: С заголовка группы
- **WHEN** курсор на заголовке свёрнутой группы `platform/route-service` и пользователь нажал `n`
- **THEN** открыта форма New MR проекта `platform/route-service`, «Из ветки» — локальная ветка его папки
