# configuration Specification

## Purpose

Хранит настройки glview (инстанс, токен, язык, параметры) и определяет, с каким хостом и каким токеном работать, включая токен из glab.

## Requirements

### Requirement: Расположение и формат конфига
Система SHALL читать конфиг из `$XDG_CONFIG_HOME/glview/config.yaml`, а при пустом `XDG_CONFIG_HOME` — из `~/.config/glview/config.yaml` на всех ОС, включая macOS. Флаг `--config` SHALL переопределять путь. Отсутствие файла MUST NOT быть ошибкой.

#### Scenario: Конфига нет
- **WHEN** файла конфига не существует
- **THEN** используются значения по умолчанию (`language: en`, `theme: terminal`) и запуск продолжается

#### Scenario: Битый YAML
- **WHEN** файл конфига содержит синтаксическую ошибку
- **THEN** запуск продолжается со значениями по умолчанию, пользователь видит предупреждение с номером строки

### Requirement: Безопасная запись конфига
Система SHALL записывать конфиг с правами `0600`, сохраняя существующие комментарии и порядок ключей. Если файл содержит токен и его права шире `0600`, система SHALL показать предупреждение.

#### Scenario: Сохранение языка
- **WHEN** пользователь переключает язык, а в конфиге есть комментарии
- **THEN** в файле меняется только `language`, комментарии остаются, права файла `0600`

#### Scenario: Широкие права
- **WHEN** конфиг с токеном имеет права `0644`
- **THEN** при старте показывается предупреждение о правах

### Requirement: Цепочка определения хоста
Система SHALL выбирать хост GitLab в порядке: хост из URL в `-p` → `host` из конфига → env `GITLAB_HOST` → хост remote текущего репозитория. Если хост не найден, система SHALL перейти к первичной настройке.

#### Scenario: Хост из remote
- **WHEN** конфига и `GITLAB_HOST` нет, а remote `origin` указывает на `gitlab.example.com`
- **THEN** используется `https://gitlab.example.com`

### Requirement: Цепочка определения токена
Система SHALL искать токен для выбранного хоста в порядке: `token` из конфига → env `GITLAB_TOKEN` → glab. Система MUST запоминать источник токена (config, env, glab) для подсказок и MUST NOT выводить токен в лог, интерфейс или stdout.

#### Scenario: Токен из env
- **WHEN** в конфиге токена нет, а `GITLAB_TOKEN` задан
- **THEN** используется токен из env, источник — env

#### Scenario: Токен нигде не найден
- **WHEN** токена нет ни в конфиге, ни в env, ни в glab
- **THEN** открывается экран первичной настройки

#### Scenario: Debug-лог
- **WHEN** включён `--debug` и выполняются запросы с токеном
- **THEN** в лог-файле токен замаскирован

### Requirement: Токен из glab
Если glab найден в PATH (или по `glab.path`) и `glab.enabled` не `false`, система SHALL запрашивать у glab токен для хоста. Сначала используется прямой запрос значения из конфига glab, затем — статус авторизации с выводом токена (для токенов в keyring). Каждый вызов glab MUST иметь таймаут 3 с и не читать stdin. Токен из glab MUST NOT сохраняться в конфиг glview.

#### Scenario: Токен в конфиге glab
- **WHEN** glab залогинен на хост и хранит токен в своём конфиге
- **THEN** glview использует этот токен, источник — glab

#### Scenario: glab не установлен
- **WHEN** glab не найден
- **THEN** шаг пропускается без ошибки

#### Scenario: glab завис
- **WHEN** вызов glab не завершился за 3 с
- **THEN** вызов прерывается, цепочка идёт дальше

### Requirement: Правила ссылок `links`
Конфиг SHALL поддерживать список `links: [{pattern, url}]`: `pattern` — регулярное выражение Go (RE2), `url` — шаблон `regexp.Expand` (`$0`, `$1`, `${name}`). Правило с пустым `pattern` или `url`, с ошибкой в регулярке или с `url`, не начинающимся с `http://`/`https://`, SHALL пропускаться с тостом-предупреждением, называющим ключ (`links[0].pattern`); остальные правила работают, запуск не прерывается. По умолчанию правил нет.

#### Scenario: Битая регулярка
- **WHEN** в конфиге `links: [{pattern: '[A-Z+', url: 'https://tracker.example.com/browse/$0'}, {pattern: '[A-Z]+-\d+', url: 'https://tracker.example.com/browse/$0'}]`
- **THEN** при старте тост-предупреждение с `links[0].pattern`, второе правило работает

#### Scenario: Группы в шаблоне
- **WHEN** правило `pattern: 'INC(\d+)'`, `url: 'https://tracker.example.com/incident/$1'`, title `INC42 hotfix`
- **THEN** ссылка `INC42 — https://tracker.example.com/incident/42`

### Requirement: Значение `theme`
Конфиг SHALL принимать `theme: terminal` (по умолчанию) и `theme: terminal-faint`. Неизвестное значение SHALL заменяться на `terminal` с тостом-предупреждением, называющим ключ `theme`; запуск не прерывается.

#### Scenario: Тема terminal-faint
- **WHEN** в конфиге `theme: terminal-faint`
- **THEN** второстепенный текст рисуется цветом по умолчанию с атрибутом Faint, без ANSI 8

#### Scenario: Неизвестная тема
- **WHEN** в конфиге `theme: foo`
- **THEN** при старте тост-предупреждение с `theme`, используется `terminal`
