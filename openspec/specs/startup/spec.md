# startup Specification

## Purpose

Определяет, что видит пользователь при запуске: первичную настройку, режим проекта или workspace, либо понятный экран, если проект не распознан.

## Requirements

### Requirement: Флаги командной строки
Система SHALL поддерживать `-p/--project <path|url>`, `--config <file>`, `--debug`, `--version`. `--version` SHALL печатать версию и завершаться без запуска интерфейса.

#### Scenario: Версия
- **WHEN** запуск `gitlab-tui --version`
- **THEN** печатается версия, код возврата 0, интерфейс не открывается

### Requirement: Выбор режима
Система SHALL выбирать режим: флаг `-p` → режим проекта; найден `.git` → режим проекта по remote; иначе → режим workspace по подпапкам.

#### Scenario: Папка проекта
- **WHEN** запуск в репозитории с remote на инстанс
- **THEN** открывается режим проекта для этого проекта

#### Scenario: Папка с проектами
- **WHEN** запуск в папке без `.git`
- **THEN** открывается режим workspace

### Requirement: Первичная настройка
Если хост или токен не найдены, либо токен отклонён (401) при старте, система SHALL показать форму с URL инстанса (подставленным из remote, если есть) и токеном (ввод скрыт). При найденном glab форма SHALL предлагать взять токен из glab. Данные SHALL проверяться запросом текущего пользователя; при успехе конфиг сохраняется с правами `0600` и открывается выбранный режим.

#### Scenario: Первый запуск
- **WHEN** конфига нет, токена в env и glab нет
- **THEN** открывается форма настройки; после ввода верного токена показывается «Вошли как @user» и открывается режим

#### Scenario: Неверный токен
- **WHEN** в форме введён неверный токен
- **THEN** форма остаётся открытой с ошибкой «токен неверный или истёк»

### Requirement: Проект не распознан
Если в режиме проекта remote указывает не на инстанс, либо проект не найден или недоступен, система SHALL показать экран с причиной (remote, его хост, хост инстанса) и действиями: выбор проекта, поиск, workspace родительской папки, выход.

#### Scenario: Remote на GitHub
- **WHEN** запуск в репозитории с remote `git@github.com:me/dotfiles.git`
- **THEN** показан экран «Проект не на <хост инстанса>» с действиями `p`, `F`, `w`, `q`

### Requirement: Пустой workspace
Если в workspace нет ни одного GitLab-проекта, система SHALL показать пустое состояние со сводкой (сколько папок просмотрено, сколько с чужим remote, сколько без `.git`) и подсказками.

#### Scenario: Нет GitLab-проектов
- **WHEN** в папке три подпапки с remote на github.com
- **THEN** показано «нет GitLab-проектов: просмотрено 3, с чужим remote 3»
