# project-search Specification

## Purpose
Быстрый переход к любому проекту или группе GitLab из любого экрана: выбор из известных проектов без сети (`p`) и глобальный поиск по инстансу (`F`).

## Requirements

### Requirement: Выбор проекта `p`
`p` SHALL открывать оверлей выбора проекта с полем ввода и секциями: ИЗ GIT REMOTE (проект текущей папки, пометка «текущий»), WORKSPACE (проекты верхнего Workspace стека), STARRED, НЕДАВНИЕ. Ввод SHALL фильтровать все секции fuzzy-сопоставлением по пути проекта с подсветкой совпавших символов; проект, попавший в несколько источников, показывается один раз — в первой по порядку секции. В строке — путь, `★` для starred, число открытых MR и активность, если они известны из кэша. Справа внизу — `показано / всего`. Оверлей SHALL работать без сетевых запросов. `↑/↓` и `ctrl+n/ctrl+p` выбор, `enter` — режим проекта, `esc` — закрыть. `ctrl+d`/`ctrl+u` и `pgdown`/`pgup` в `p` и `F` SHALL сдвигать выбор на полстраницы видимого списка (секции считаются строками) и не попадать в поле ввода; в хелпе `?` они перечислены в группе клавиш оверлеев.

#### Scenario: Полстраницы
- **WHEN** в `p` 30+ строк, набран текст и нажат `ctrl+d`, затем `ctrl+u`
- **THEN** выбор сдвинулся на полстраницы вниз и вернулся, введённый текст не изменился

#### Scenario: Без сети
- **WHEN** открыт `p` и набрано `rout`
- **THEN** в секциях только проекты с fuzzy-совпадением `rout`, к GitLab не ушло ни одного запроса

#### Scenario: Пусто
- **WHEN** ввод не совпал ни с одним проектом
- **THEN** показано «ничего не найдено — F поиск по GitLab»

### Requirement: Starred и недавние проекты
Список starred SHALL храниться в кэше на диске и обновляться в фоне при старте, если снимок старше 1 часа; ошибка фонового обновления SHALL оставлять прежний снимок без тоста (только debug-лог). Недавние проекты SHALL записываться при каждом открытии экрана проекта (последние 20, новые первыми) в файл состояния и переживать перезапуск. Снимок starred и список недавних SHALL храниться отдельно для каждого хоста: picker `p` не показывает проекты другого инстанса.

#### Scenario: Недавний проект
- **WHEN** пользователь открыл проект `qa/e2e-routes`, вышел и снова запустил glview в другой папке
- **THEN** `p` показывает `qa/e2e-routes` первым в секции НЕДАВНИЕ

#### Scenario: Другой хост
- **WHEN** пользователь работал с `gitlab.example.com`, затем запустил glview с другим хостом
- **THEN** `p` не показывает starred и недавние проекты `gitlab.example.com`

### Requirement: Глобальный поиск `F`
`F` SHALL открывать оверлей поиска с полем ввода и разделами «Проекты» и «Группы». Пока в поле меньше 3 символов, поиск не выполняется. С 3 символов SHALL сразу показываться локальные fuzzy-совпадения из источников `p` (с пометкой «локально»), а через 300 мс после последнего ввода — выполняться один серверный запрос проектов и групп; его результаты подмешиваются без дублей по пути. Запрос, устаревший из-за нового ввода, SHALL отменяться, его ответ — выбрасываться. Пока идёт запрос — строка «◐ ищем…», ошибка — строка с текстом ошибки в оверлее, локальные совпадения остаются.

#### Scenario: Быстрый ввод
- **WHEN** в `F` быстро набрано `router` (6 символов, паузы меньше 300 мс)
- **THEN** к GitLab ушёл ровно один поисковый запрос — по `router`

#### Scenario: Локальное и серверное
- **WHEN** набрано `route`, локально известен `platform/route-service`, сервер вернул его же и `logistics/route-api`
- **THEN** в «Проектах» `platform/route-service` один раз с пометкой «локально» и `logistics/route-api`

### Requirement: Открытие проекта и группы из поиска
`enter` на проекте в `p` или `F` SHALL открывать экран проекта на табе MRs над верхним Workspace стека (`esc` вернёт в него), экраны над этим Workspace закрываются; без Workspace в стеке проект кладётся над стартовым корнем. Если путь проекта совпадает с одной из известных локальных папок (текущая папка, папки workspace), экран проекта SHALL работать с этой папкой. `enter` на группе в `F` SHALL класть над стартовым корнем Workspace из проектов группы (прежний Workspace группы закрывается); `esc` на нём возвращает к стартовому экрану.

#### Scenario: Проект из workspace
- **WHEN** в Workspace открыт MR detail, нажат `p`, выбран `infra/router-configs`
- **THEN** стек — Workspace, под ним ничего, сверху экран проекта `infra/router-configs`; `esc` возвращает в Workspace

#### Scenario: Группа
- **WHEN** в `F` выбрана группа `platform`
- **THEN** открыт Workspace с шапкой `group: platform · workspace · N проектов`, `esc` на нём возвращает к стартовому экрану
