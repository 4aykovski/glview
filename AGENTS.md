# AGENTS.md

Инструкции для любых ИИ-агентов (Claude Code, Codex, Cursor и др.), работающих с этим репозиторием. Полные правила проекта — в [CLAUDE.md](CLAUDE.md), они обязательны для всех агентов.

## Конфиденциальность — жёсткий запрет

Репозиторий публичный. **НИЧЕГО конфиденциального не должно попадать в репозиторий, историю git и GitHub — никогда.** Запрещены любые данные рабочих систем: хосты и URL, названия групп/проектов/сервисов/организаций, номера и ссылки MR/issues/пайплайнов/задач, имена, логины и e-mail коллег, токены и ключи, логи, ответы API, отчёты ботов, снимки экранов, куски рабочего кода. В фикстурах, тестах и документации — только выдуманные данные (`gitlab.example.com`, `anna.k`, `!479`).

Перед каждым коммитом: `make test lint confidential` зелёные, `git config --get core.hooksPath` = `scripts/githooks` (иначе `make hooks`), ручной просмотр `git diff --cached` и сообщения коммита. Хуки `scripts/githooks/*` обходить запрещено (`--no-verify`, `-n`, отключение `core.hooksPath`, правка хука). Подробности — раздел «Конфиденциальность» в CLAUDE.md.

## Задачи — GitHub Issues

Задачи ведутся только в [GitHub Issues](https://github.com/4aykovski/glview/issues), дорожная карта — [#36](https://github.com/4aykovski/glview/issues/36); текстового списка задач в репозитории нет. Перед работой — `gh issue view <N>`; коммиты — `T11: … (#11)`; по ходу отмечать чекбоксы «Готово, когда», закрывать issue после пуша, когда отмечено всё; новую работу и найденные проблемы — заводить issues с вехой и меткой. Issues публичны: правило о конфиденциальности выше касается и их. Подробности — раздел «Задачи — GitHub Issues» в CLAUDE.md.
